## No IDE bridge tools available

No first-party `sigil_*` IDE bridge tools are registered yet (and no user-configured
MCP tools either). The bridge catalog (BridgeToolCatalog) seeds the tool registry
when the Sigil harness connects — this state usually means tool discovery has not
run yet. This manifest REGENERATES AUTOMATICALLY at every connect and after each
tool-discovery run (SigilToolsManifestBridge) — there is nothing to re-run by hand.
